# Painel administrativo

Status: PLANEJADO.

O painel administrativo podera concentrar funcionalidades internas de operacao da PrintLab.

## Comportamento planejado

- Gerenciar produtos e variantes.
- Acompanhar pedidos.
- Consultar dados de cliente necessarios para atendimento.
- Ver informacoes relacionadas a producao 3D.
- Apoiar controle basico de custos, tempo estimado e material.

## Limites

- Nao ha painel administrativo implementado nesta fase.
- Autenticacao, autorizacao e papeis administrativos ainda nao foram definidos.
- Nenhuma interface interna deve ser criada sem regras de acesso claras.

## Decisoes pendentes

- Modelo de usuarios administrativos.
- Politica de permissoes.
- Logs de auditoria.
- Fluxo operacional de producao.
