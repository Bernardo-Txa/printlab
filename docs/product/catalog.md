# Catalogo

Status: PLANEJADO.

O catalogo devera apresentar produtos da PrintLab de forma clara, com dados suficientes para compra e producao futura.

## Comportamento planejado

- Listar produtos publicados.
- Exibir pagina de detalhe de produto.
- Associar produtos a categorias.
- Exibir imagens de produto.
- Exibir variantes quando existirem.
- Diferenciar produtos prontos de produtos sob demanda quando essa regra for aprovada.

## Limites

- Nao ha catalogo implementado nesta fase.
- Nao ha schema aprovado para produtos.
- Nao ha integracao com storage de imagens.

## Decisoes pendentes

- Modelo final de categorias.
- Campos obrigatorios de produto.
- Estrategia de imagem principal e galeria.
- Regras de disponibilidade para produtos sob demanda.
